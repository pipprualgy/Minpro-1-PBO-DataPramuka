# Minpro 1 PBO Data Pramuka
## Deskripsi Singkat
Program Pendataan Anggota Pramuka merupakan program berbasis Java yang digunakan untuk mengelola data keanggotaan Pramuka secara sederhana melalui sistem CRUD (Create, Read, Update, Delete). Program ini dibuat menggunakan ArrayList sebagai tempat penyimpanan data selama program berjalan. Program memiliki tiga class utama, yaitu GugusDepan, Kwarran, dan AnggotaPramuka, sedangkan Minprodatapramuka digunakan sebagai class utama untuk menjalankan program. Class GugusDepan digunakan untuk menyimpan data kode Gugus Depan, nama Gugus Depan, dan pangkalan. Class Kwarran digunakan untuk menyimpan ID dan nama Kwartir Ranting. Sementara itu, class AnggotaPramuka digunakan untuk menyimpan ID anggota, nama anggota, jenis kelamin, nomor Gugus Depan, dan ID Kwartir Ranting. Setiap class juga menerapkan constructor untuk menginisialisasi data serta method tampilkanData() untuk menampilkan informasi objek.

## Alur Program

Program dijalankan melalui class Minprodatapramuka yang berfungsi sebagai entry point dengan method main(). Pada awal program, objek Scanner digunakan untuk menerima input dari pengguna, kemudian dibuat tiga ArrayList, yaitu anggotaPramuka untuk menyimpan data anggota, gugusDepan untuk menyimpan data Gugus Depan, dan kwarran untuk menyimpan data Kwartir Ranting. Setelah itu, program menampilkan menu utama yang terdiri dari pilihan Gugus Depan, Kwartir Ranting, Anggota Pramuka, dan Keluar. Menu utama dijalankan menggunakan perulangan do-while sehingga program akan terus berjalan sampai pengguna memilih menu keluar. Pemilihan menu dilakukan menggunakan input angka dari pengguna dan diproses menggunakan percabangan switch-case.

Jika pengguna memilih menu Gugus Depan, program menampilkan submenu yang menyediakan pilihan tambah, lihat, update, hapus, dan kembali. Pada proses tambah, pengguna memasukkan kode Gugus Depan, nama Gugus Depan, dan pangkalan, kemudian data tersebut dibuat menjadi objek GugusDepan menggunakan constructor dan dimasukkan ke dalam ArrayList gugusDepan. Pada proses lihat, program melakukan perulangan terhadap isi ArrayList untuk menampilkan seluruh data Gugus Depan. Pada proses update, pengguna memilih nomor data yang ingin diubah, kemudian program mengambil objek tersebut menggunakan get() dan mengubah data kode, nama, serta pangkalannya. Sementara itu, proses hapus menggunakan remove() untuk menghapus data berdasarkan nomor yang dipilih pengguna.

Jika pengguna memilih menu Kwartir Ranting (Kwarran), alurnya hampir sama dengan menu Gugus Depan. Pengguna dapat menambahkan data dengan memasukkan ID dan nama Kwarran, kemudian data dibuat menjadi objek Kwarran dan disimpan ke dalam ArrayList. Pengguna juga dapat melihat seluruh data Kwarran melalui perulangan, memperbarui data yang dipilih, serta menghapus data menggunakan nomor yang tersedia. Setiap proses dilakukan melalui submenu CRUD sehingga pengguna dapat mengelola data Kwarran tanpa harus menghentikan program.

Jika pengguna memilih menu Anggota Pramuka, program menampilkan submenu tambah, lihat, update, hapus, dan kembali. Pada proses tambah anggota, pengguna memasukkan ID anggota, nama anggota, jenis kelamin, nomor Gugus Depan, dan ID Kwartir Ranting. Data tersebut kemudian digunakan untuk membuat objek AnggotaPramuka melalui constructor dan disimpan ke dalam ArrayList anggotaPramuka. Pada proses lihat, program melakukan perulangan terhadap ArrayList untuk menampilkan seluruh data anggota. Pada proses update, pengguna memilih data anggota berdasarkan nomor, kemudian program mengubah ID, nama, jenis kelamin, nomor Gugus Depan, dan ID Kwartir Ranting. Pada proses hapus, data anggota yang dipilih akan dihapus dari ArrayList.

Setelah pengguna selesai melakukan pengelolaan data, pengguna dapat memilih menu Keluar pada menu utama. Program kemudian menampilkan pesan bahwa program selesai dan menghentikan perulangan utama. Setelah perulangan selesai, objek Scanner ditutup menggunakan input.close(). Dengan demikian, program akan terus menerima input dan menjalankan proses CRUD selama pengguna belum memilih menu keluar.
